# DMV Outings

A static site (GitHub Pages) of DC-area outings. Upcoming events show first; passed events move to the archive automatically.

To update each week: append new events to `data.json` with `added` set to that day, and bump `updated`. Never delete an event.
Each event: id, title, start, end, time, venue, area, price, fit (family, solo, friends, couples), why, urgency, source (organizer's own page), verified (date checked), added, lat/lng (reserved for a future map).
Keep personal calendars, home location and names off this site.
